# 🎙 Transcriber

Локальная транскрипция аудио через **faster-whisper** (CTranslate2) на NVIDIA GPU или на процессоре. Всё работает на вашем компьютере, интернет нужен только чтобы один раз скачать модель.

Бесплатно, без ограничений и без ключей. Телеграм-канал автора: [ArtEmotion3D](https://t.me/ArtEmotion3DGroup).

## Установка

1. Нужны Windows 10/11 и [Python 3.10+](https://www.python.org) (при установке отметьте «Add Python to PATH»).
2. Скачайте проект: зелёная кнопка **Code → Download ZIP**, распакуйте в любую папку.
3. Запустите `start.bat`. При первом запуске он сам поставит библиотеки (и CUDA, если есть видеокарта NVIDIA), скачает модель и создаст ярлык **Transcriber** на рабочем столе. Это займёт несколько минут.

## Запуск

Двойной клик по ярлыку **Transcriber** на рабочем столе. Откроется отдельное окно приложения (Edge в режиме приложения, без вкладок и адресной строки), сервер работает в свёрнутом окне консоли.

- Закрыли окно приложения: через ~30 секунд сервер сам выключится (если в этот момент ничего не распознаётся).
- Нажали ярлык ещё раз, пока всё запущено: просто откроется ещё одно окно.
- Библиотеки ставятся в `%LOCALAPPDATA%\Transcriber\venv`, системный Python не меняется.
- Если ярлык пропал, запустите `Установить ярлык.bat`.

## Как пользоваться

1. Перетащите аудио (или видео) в окно или нажмите «выберите файл».
2. Выберите **модель** (large-v3 — самая точная), **точность**, **язык** и нужны ли **таймкоды**.
3. «▶ Начать». Текст появляется по ходу распознавания, видна скорость (× реального времени) и сколько осталось.
4. «⏹ Стоп» останавливает в любой момент: уже распознанный кусок остаётся, его можно скопировать или скачать.
5. «📋 Копировать», «⬇ SRT» (субтитры), «⬇ TXT» (с таймкодами, если они включены).

Каждый результат автоматически сохраняется в папку `results` (кнопка «📂 Сохранённые»), так что закрытое окно не теряет текст. Если окно случайно обновили или закрыли во время работы, откройте его снова: текст и прогресс подтянутся. Настройки запоминаются между запусками.

### Точность

| Режим | Что делает | Когда |
|---|---|---|
| Быстро | beam 1 | черновик, длинные записи |
| Обычная | beam 5 (по умолчанию) | почти всегда |
| Максимальная | beam 10, patience 1.5 | сложная запись, медленнее |

### Язык

Русский, English, Українська, Deutsch, Français, Español или «Автоопределение» (Whisper сам определит язык по началу записи).

## GPU и запасной режим

Распознавание идёт на GPU (CUDA, float16). Если с GPU что-то не так, приложение само переключится на процессор (int8) и покажет жёлтое предупреждение: работать будет, но медленнее. Внизу окна всегда написано, на чём идёт распознавание.

CUDA Toolkit ставить не нужно: нужные DLL идут вместе с пакетами `ctranslate2` и `nvidia-cublas-cu12`, `start.bat` ставит их сам, если находит видеокарту NVIDIA.

Whisper иногда «застревает» на длинных записях: повторяет одну фразу («Вот. Вот. Вот.…») поверх настоящей речи или начинает выдавать по одному слову на строку. Приложение это замечает, убирает плохие строки (они на секунду исчезнут из окна) и распознаёт этот кусок заново, так что текст не пропадает.

Скорость, например, на RTX 3080 Ti Laptop с large-v3: примерно 10–15× реального времени (час записи за 4–6 минут). Перед началом текста есть пауза: файл читается и в нём ищется речь, около 20 секунд на час записи.

## Модели

Все модели лежат в `Transcriber/models/` — нигде больше (в кэше HuggingFace ничего не остаётся).

**Встроенные** (tiny, base, small, medium, large-v3) скачиваются в `models/<имя>` автоматически при первом использовании, с прогрессом в окне. В списке моделей у каждой есть бейдж: «✓ в папке» или «⬇ скачается при запуске».

**Свои модели:**

1. Скачайте модель с HuggingFace (любую совместимую с faster-whisper, например `Systran/faster-whisper-large-v3`).
2. Положите **папку** с файлами модели (`model.bin`, `config.json`, `tokenizer.json`, …) в `Transcriber/models/`.
3. Нажмите ⟳ в панели «Загруженные модели»: модель появится в списке и в выборе модели.

В памяти видеокарты держится одна модель: при переключении на другую предыдущая выгружается.

## Требования

- Windows 10/11, Python 3.10+
- NVIDIA GPU с драйвером (проверка: `nvidia-smi`); без него будет работать на процессоре
- ~3 ГБ видеопамяти для large-v3 (float16)

## Структура

```
Transcriber/
├── app.py              # Flask + SocketIO сервер, распознавание, окно приложения
├── requirements.txt
├── start.bat           # Установка и запуск (ярлык на рабочем столе указывает сюда)
├── make_shortcut.ps1   # Создаёт ярлык на рабочем столе
├── transcriber.ico     # Иконка ярлыка и окна
├── static/             # app.js, style.css, socket.io.min.js (всё локально, без интернета)
├── templates/          # index.html
├── models/             # ВСЕ модели: встроенные (скачиваются сами) + свои
├── results/            # Автосохранённые транскрипции (.txt)
└── uploads/            # Временная копия загруженного файла (очищается)
```

Папки `models`, `results` и `uploads` создаются сами при первом запуске.
